# LINVISUALS — GitHub Pages

## Обновить уже опубликованный сайт

1. Распакуйте архив.
2. Откройте ваш репозиторий GitHub `LinVisual`.
3. Нажмите **Add file → Upload files**.
4. Перетащите `index.html`, `.nojekyll` и папку `assets` целиком (внутри `assets` лежит `linvisuals-logo.png`).
5. Выберите **Commit changes**.
6. Подождите 1–3 минуты и обновите сайт с жёсткой перезагрузкой: Ctrl+F5.

Важно: структура в репозитории должна быть такой:
- index.html
- .nojekyll
- assets/linvisuals-logo.png
- assets/minecraft-scene.png

Ссылки на скачивание и Discord сохранены из исходного сайта. Проверьте, что они актуальны.
